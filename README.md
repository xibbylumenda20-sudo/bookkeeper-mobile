# Bookkeeper Mobile Android Project

Phone-first bookkeeping app source. The accounting UI is offline-first and stores transactions locally.

## Build an APK for free from Android only

1. Create a free GitHub account (if you do not already have one).
2. Create a new repository, e.g. `bookkeeper-mobile`.
3. Upload this entire project.
4. GitHub Actions will build the Android debug APK.
5. Open the completed workflow run → Artifacts → download `bookkeeper-debug-apk`.
6. On Android, open the APK and allow installation from that source if Android asks.

## Important
This project is a buildable starting point, but the final accounting engine should be reconciled against the existing Excel workbook before real accounting use.
